# shiori-s-portofolio
This project analyzes Olympic medal data to investigate the United States' performance across different sports and Olympic locations.

I cleaned and filtered the dataset to examine questions such as:
Which sports have earned the most medals for the United States?
At which Olympic locations did the United States win the most medals?
How does the number of U.S. medals vary across different sports and locations?

# Project Goal

The goal of this project was to use Python to work with real-world data and find meaningful patterns within it. Rather than looking at the data as a large collection of numbers, I used data cleaning, filtering, and analysis to answer specific questions about U.S. Olympic performance.

# What I Learned
Through this project, I practiced:
Cleaning and organizing data
Filtering datasets based on specific conditions
Analyzing patterns in data
Using Python to work with a larger dataset
Turning a question into a data-driven analysis
